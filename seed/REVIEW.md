# Questions to fact-check

Every question was written to be checkable and avoids stats that change week to week. These are the ones worth a second look: mostly records that could have changed in the 2025-26 seasons (after my knowledge cutoff) or exact figures I'm not completely sure of.

To fix one, edit its JSON file in this folder, run `python3 seed/validate.py`, then restart the API in Development (or run the seed command); the loader updates changed questions in place.
